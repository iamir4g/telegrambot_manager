# فازبندی دستیار AI فیناپ (Credit First)

هدف: نسخه سبک قبل از ۱۴ آبان — تیم فیناپ محتوا را از پنل مدیریت می‌کند؛ بات از دانش تأییدشده جواب می‌دهد؛ بعداً به محصول چندرویدادی گسترش می‌یابد.

## پیش‌فرض‌ها

| موضوع | انتخاب |
|--------|--------|
| ثبت‌نام رویداد اول | لینک خارجی + پیگیری از بات/پنل |
| بلیت / درگاه / کارت‌به‌کارت | خارج از MVP (امکان‌سنجی جدا) |
| انتشار کانال تلگرام | فاز ۲ |
| تنظیمات تلگرام و دانش بات | همه از بک‌آفیس از فاز ۱ |
| استک | NestJS + React (Mantine, TanStack Query, RHF) + TypeScript |
| معماری | Feature-based؛ بدون god hook / god service |
| دیتابیس | SQLite + Prisma |
| AI | OpenAI-compatible + topic tree + فقط دانش approved |

جزئیات معماری کد: [ARCHITECTURE.md](./ARCHITECTURE.md)

## تنظیمات پنل (الزام فاز ۱)

**تلگرام:** bot token، channel id، webhook/polling، پیام‌های ثابت، دستورها، opt-in، تست اتصال، kill switch  
**دانش/AI:** FAQ، درخت موضوعات، تنظیمات LLM، پرامپت محدود  
**رویداد:** برنامه، سخنران، لوکیشن، لینک‌ها، اسپانسر، راهنمای روز

## فازها

### فاز ۰ — اسکلت (۲–۳ روز)

- Monorepo feature-based
- Auth JWT + نقش‌ها
- Docker Compose
- الگوی مرجع یک فیچر (FAQ)

### فاز ۱ — MVP

- CRUD محتوا + FAQ + topic tree
- تنظیمات کامل تلگرام از پنل
- بات با orchestrator محدود
- صف ارجاع + گزارش حداقلی

### فاز ۲ — روز رویداد

- راهنمای روز سریع‌ویرایش
- خبرها + انتشار کانال
- کلیک‌ترکر ثبت‌نام + harden

### فاز ۳ — پس از رویداد

- نظرسنجی + خلاصه AI
- گزارش کامل + audit
- آماده‌سازی multi-event

## امکان‌سنجی جدا

| قابلیت | نفر-روز تقریبی | زمان‌بندی |
|--------|----------------|-----------|
| خرید بلیت داخلی | ۸–۱۴ | رویداد بعد |
| درگاه پرداخت | ۶–۱۰ | جدا از فاز ۱ |
| کارت‌به‌کارت + تأیید دستی | ۴–۶ | در صورت نیاز |
| انتشار کانال از پنل | ۲–۳ | فاز ۲ |

برآورد تا پایان فاز ۲: حدود ۱۸–۲۵ نفر-روز.
